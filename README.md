# サブハック（サブスクハック）｜サブスク・固定費の合計計算サイト

タップでサブスクを選ぶと月額・年額の合計を計算し、シェア用の合計カードを作るサイトです。
ビルド不要の静的サイトなので、フォルダごと Netlify / Cloudflare Pages / GitHub Pages / レンタルサーバーに置けば公開できます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | デザイン |
| `app.js` | 動作（選択・合計・カード・画像保存・検索） |
| `data.js` | サービス一覧と料金（約240サービス・15カテゴリ） |
| `config.js` | サイト名・ハッシュタグ・**アフィリエイトリンク** |

## アフィリエイトの設定（config.js）

1. **サービス別リンク** `AFFILIATE`
   `data.js` のサービス `id` をキーに URL を入れると、
   - プラン選択シートの下に「公式サイトを見る PR」ボタン
   - 合計カード画面の「あなたのサブスクの公式キャンペーン」欄
   に自動で表示されます。
   ```js
   const AFFILIATE = {
     unext: 'https://px.a8.net/svt/ejp?a8mat=xxxx',
     ahamo: 'https://...',
   };
   ```
2. **見直し・おすすめ枠** `RECOMMENDS`
   合計カード画面に条件付きで出る広告枠です。`url` を入れた枠だけ表示されます。
   例：スマホ代が月4,000円以上の人にだけ格安SIMの案件を出す、など。

リンクには `rel="sponsored"` と「PR」表記が自動で付きます。

## サービスの追加

`data.js` の該当カテゴリに1行追加します。

```js
{ id: 'newservice', n: '新サービス', c: '#FF6600', t: 'N', p: [['月額プラン', 980], ['年額（月割り）', 817]] },
```

- `multi: true` … 同じサービスを何件でも登録できる（推し・ジムなど）
- プランの4番目に `true` … 「新規受付を終了したプラン」に分けて表示
- `img: 'logos/xxx.png'` … ロゴ画像（使用許諾のある画像のみ）

## 公開前のチェック

- `config.js` の `SITE.url` を本番URLに変更
- 料金は目安です。各社公式サイトで確認・更新してください
- 各ASPの規約（PR表記・商標の扱い・リスティング制限など）を確認してください

## 見直しレポート（report-config.js）

合計カード画面の最後に「スマホ・光回線・電気代・クレジットカード」の見直しレポートが出ます。
比較候補・料金・キャッシュバック・還元率・アフィリエイトURLは `report-config.js` で編集します。

- `url` を入れると「申し込む（PR）」ボタンが出ます
- 光回線の `cashback` を入れると「実質月額」で比較します
- 電気の `rate`（例: 0.05 = 5%安い）を入れると節約額が出ます。0 なら試算ボタンだけ出します
- `set` に入れたサービスを使っている人には「セット割・相性◎」として優先表示します

## アイコン（icons.js）

各サービスの公式サイトのファビコンを表示します。ドメインは `icons.js` の `ICON_DOMAINS` で変更できます。
読み込めない場合は色付きの文字アイコンになります。

## 通知・相談・有料会員（config.js の LINE / MEMBERSHIP）

- `LINE.id` に公式アカウントのベーシックID（@xxxx）、`LINE.addFriendUrl` に友だち追加URLを入れると、
  「友だち追加（無料）」「LINE通知をオンにする」「有料会員の相談（月額¥400で相談し放題）」がLINEにつながります
  （利用者の予定・サブスク一覧が入力済みのメッセージとして開きます）
- `MEMBERSHIP.joinUrl` に決済リンク（Stripe など）を入れると、申し込みボタンはそちらに飛びます
- 「カレンダーに追加」は予定を .ics ファイルにして、スマホのカレンダーで前日に通知します

※LINEから自動で通知を送るには、LINE公式アカウントの予約配信、または Messaging API とサーバーが必要です。

## 管理画面（admin.html）

本部用の管理画面です： https://www.sabu-hack.com/admin.html

- LINE公式アカウント（ベーシックID・友だち追加URL）、有料会員、サービス別アフィリエイト、見直しレポートの乗り換え先・申込URL、おすすめ枠、基本設定を編集できます
- 「保存して公開」で `settings.json` が GitHub 上で更新され、1〜2分で公開サイトに反映されます
- ログインには GitHub の Fine-grained token（対象: このリポジトリだけ / Permissions → Contents: Read and write）を使います
- 変更履歴は GitHub の `settings.json` の履歴で確認・復元できます
- `config.js` / `report-config.js` は初期値です。`settings.json` にある項目はそちらが優先されます

## 明細スクショの読み取り（scan.js）

「カード明細のスクショで自動入力」から画像を選ぶと、ブラウザ内の文字認識（Tesseract.js）で読み取り、サービス名と金額を見つけます。画像は外部に送信されません。

- 明細での表記（例：NETFLIX.COM、GOOGLE*YOUTUBE、KDDI）は `scan.js` の `STATEMENT_KEYS` で追加できます
- App Store など中身が特定できない決済は `STATEMENT_GENERIC` で名前つきの項目として追加します
- 半角カナの小さい文字は読み取り精度が下がることがあります

## アフィリエイト管理（金庫・admin-vault.js）

管理画面の「🗂 アフィリエイト管理（金庫）」で、ASPのログイン情報と登録しているアフィリエイト案件（状態・報酬・成果条件・URL）を管理します。

- 中身は「金庫のパスワード」（12文字以上）で暗号化して `vault.json` に保存します（PBKDF2-SHA256 60万回 + AES-256-GCM）。リポジトリは公開なので、暗号化前の内容はどこにも保存しません
- パスワードを忘れると中身は戻せません。GitHubのトークンとは別のパスワードにしてください
- 「サイトで使っているリンクを取り込む」で、サイトに設置済みのリンクから案件一覧を作れます。各案件の「サイトでの設置場所」は自動で表示されます
- 10分間操作がないと自動でロックされます

## 合法の裏技（hacks.html / hacks-data.js / hacks.js）

公式の制度やルールを“設計どおり”に使う裏技78件・10カテゴリの一覧ページです（2026-11-04〜05時点の調査）。X・ブログで話題のものは出典に「二次情報」と書き、一部未検証の印を付けています。

- `hacks.html` … 一覧ページ。Top10、カテゴリ別、各項目の手順・注意・出典
- トップページの「知らないと損する、合法の裏技」欄と、固定費レポートの「知らないと損する、合法の裏技」欄（登録しているサービスに関係するものを優先して表示）にも出ます
- 内容の編集は `hacks-data.js`。`sids` に data.js のサービスIDを入れると、そのサービスを登録した人のレポートに出ます
- **全文を読める条件**（`hacks-data.js` の `HACKS_GATE`、settings.json の `HACKS_GATE` でも上書き可）
  - `share: true` … このページをシェア（LINEで送る／Xでシェア／リンクをコピー）すると全文が読めます
  - `passcode` … 合言葉（現在「サブハック2026」）を入れても読めます。LINE公式アカウントのあいさつメッセージに書いておく想定です。全角・半角の違いは気にせず通ります
  - `free: true` の項目（サブスク・解約の5件）は条件なしで読めます
  - 静的サイトなので、シェアしたかは確かめられず、ソースを見れば読める「ゆるい制限」です。合言葉を変えると、合言葉で開いた人は入れ直しになります
- ヒドゥンシティ発券（運送約款違反になり得る）とJRパス（在住者は対象外）は収録していません
- 金額・キャンペーン（例：JALのPonta増量は2026-12-31まで）は期限があるので、定期的に見直してください
