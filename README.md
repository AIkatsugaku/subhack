# サブスクまとめ（サブスク月額合計計算サイト）

タップでサブスクを選ぶと月額・年額の合計を計算し、シェア用の合計カードを作るサイトです。
ビルド不要の静的サイトなので、フォルダごと Netlify / Cloudflare Pages / GitHub Pages / レンタルサーバーに置けば公開できます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | デザイン |
| `app.js` | 動作（選択・合計・カード・画像保存・検索） |
| `data.js` | サービス一覧と料金（約240サービス・15カテゴリ） |
| `config.js` | サイト名・ハッシュタグ・**アフィリエイトリンク** |

## アフィリエイトの設定（config.js）

1. **サービス別リンク** `AFFILIATE`
   `data.js` のサービス `id` をキーに URL を入れると、
   - プラン選択シートの下に「公式サイトを見る PR」ボタン
   - 合計カード画面の「あなたのサブスクの公式キャンペーン」欄
   に自動で表示されます。
   ```js
   const AFFILIATE = {
     unext: 'https://px.a8.net/svt/ejp?a8mat=xxxx',
     ahamo: 'https://...',
   };
   ```
2. **見直し・おすすめ枠** `RECOMMENDS`
   合計カード画面に条件付きで出る広告枠です。`url` を入れた枠だけ表示されます。
   例：スマホ代が月4,000円以上の人にだけ格安SIMの案件を出す、など。

リンクには `rel="sponsored"` と「PR」表記が自動で付きます。

## サービスの追加

`data.js` の該当カテゴリに1行追加します。

```js
{ id: 'newservice', n: '新サービス', c: '#FF6600', t: 'N', p: [['月額プラン', 980], ['年額（月割り）', 817]] },
```

- `multi: true` … 同じサービスを何件でも登録できる（推し・ジムなど）
- プランの4番目に `true` … 「新規受付を終了したプラン」に分けて表示
- `img: 'logos/xxx.png'` … ロゴ画像（使用許諾のある画像のみ）

## 公開前のチェック

- `config.js` の `SITE.url` を本番URLに変更
- 料金は目安です。各社公式サイトで確認・更新してください
- 各ASPの規約（PR表記・商標の扱い・リスティング制限など）を確認してください
