本部ログイン

GitHub のアクセストークンでログインします。トークンを持っている人だけが設定を保存できます。

トークンの作り方
  1. GitHub にログインし、Fine-grained token の作成画面を開く
  2. 「Repository access」で Only select repositories を選び、 を選ぶ
    ※「Public repositories」のままだと読み取り専用になり、保存できません
  3. 「Permissions」の Repositories の箱で「＋ Add permissions」→ Contents を追加し、右側を Read and write にする
    ※「Account」の箱ではありません。追加直後は「Read-only」なので必ず切り替えてください
  4. 「Generate token」（作り直す場合は「Update」）を押し、トークン（github_pat_…）をここに貼り付ける

本部のスタッフごとにトークンを分けておくと、誰が変更したか履歴でわかります。
