本部ログイン

オーナーから受け取ったIDとパスワードでログインします。

はじめての設定・オーナーの登録（GitHub のトークンが必要）

リポジトリ に保存できる GitHub のトークンを持っている人が、オーナー（メンバーを追加できる人）としてIDとパスワードを作ります。トークンはサーバーに預けられ、以後の保存に使われます。

トークンの作り方：Fine-grained token の作成画面で「Only select repositories」→ このリポジトリを選び、「Repositories」の権限で Contents を Read and write にする。
